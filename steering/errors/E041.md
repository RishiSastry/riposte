# E041 — illegal action for this block

**Cause:** `on forced_switch` fires after a faint or forced switch-out, when the only legal
actions are **switches**. A `use` (move) action there is a compile error.

**Broken:**
```
on forced_switch:
  rule a:
    when exists bench b where resists(b, opponent.active.primary_type)
    do use "uturn"
  otherwise:
    do switch_to best bench by hp_fraction(it)
```

**Fixed:** use a switch action:
```
on forced_switch:
  rule a:
    when exists bench b where resists(b, opponent.active.primary_type)
    do switch_to best bench by matchup_score(it, opponent.active)
  otherwise:
    do switch_to best bench by hp_fraction(it)
```

Moves (including pivot moves like U-turn) belong in `on turn`. `on forced_switch` is
switch-only.
