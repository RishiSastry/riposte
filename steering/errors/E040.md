# E040 — block must end with an `otherwise` rule

**Cause:** Every block (`on turn`, `on forced_switch`) must end with exactly one `otherwise:`
rule, and it must be **last**. This guarantees the policy is total — it always produces an
action.

**Broken:** no `otherwise`:
```
on turn:
  rule press:
    when likely(can_ko(my.active, opponent.active))
    do use strongest_move against opponent.active
```

**Fixed:** add a final `otherwise`:
```
on turn:
  rule press:
    when likely(can_ko(my.active, opponent.active))
    do use strongest_move against opponent.active
  otherwise:
    do use strongest_move against opponent.active
```

If you put `otherwise` before other rules, you'll also get E040 — it must be the last rule,
since everything after it would be unreachable.
