# E032 — effectiveness is categorical; compare with at_least/at_most

**Cause:** `effectiveness(...)` returns a **category**, not a number, so you can't compare it
with `>`, `<`, or `=` against a number. (Quirk Q2.)

**Broken:**
```
when effectiveness(opponent.active.primary_type, my.active) > 2
do switch_to best bench by matchup_score(it, opponent.active)
```

**Fixed:** use `at_least` / `at_most` with a category name:
```
when effectiveness(opponent.active.primary_type, my.active) at_least super
do switch_to best bench by matchup_score(it, opponent.active)
```

Categories, ordered: `immune < strongly_resisted < resisted < neutral < super < overwhelming`.
So `at_least super` means 2× or 4×; `at_most resisted` means 0.5× or less.
