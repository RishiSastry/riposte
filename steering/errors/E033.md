# E033 — type mismatch

**Cause:** An expression has the wrong type for where it's used — e.g. a predicate argument of
the wrong kind, comparing two incomparable types, or a non-bool where a bool is required.

**Broken:** `when my.active.hp_fraction do ...`   (a `frac` where a `bool` is needed)
**Fixed:** `when my.active.hp_fraction < 0.5 do ...`

Check the predicate's signature with `predicate_reference("<name>")`.
