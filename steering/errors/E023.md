# E023 — `it` used outside an exists/best binding

**Cause:** `it` is only bound inside a selector's `by <key>` expression (`best … by …`). It
is **not** available in a plain `when` condition or an action target.

**Broken:**
```
when it.hp_fraction < 0.5
do use strongest_move against opponent.active
```

**Fixed:** in a `when`, name the mon you mean (`my.active`, `opponent.active`), or use an
`exists … where` binder:
```
when my.active.hp_fraction < 0.5
do use strongest_move against opponent.active
```

`it` is correct here, inside a selector key:
```
do switch_to best bench by hp_fraction(it)
```
