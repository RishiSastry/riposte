# E031 — resolver applied to a value that is already a fact

**Cause:** You wrapped a resolver (`likely`/`worst_case`/`best_case`) around something that is
already a `bool` fact. Resolvers only make sense for `tribool` (estimate-based) values. This
usually means cargo-culting resolvers onto every predicate.

**Broken:** `resists` returns a plain `bool` (typing is a fact), so there is nothing to resolve:
```
when likely(resists(my.active, opponent.active.primary_type))
do switch_to best bench by hp_fraction(it)
```

**Fixed:** drop the resolver:
```
when resists(my.active, opponent.active.primary_type)
do switch_to best bench by hp_fraction(it)
```

Rule of thumb: a resolver belongs on `can_ko`, `guaranteed_ko`, `outspeeds`, `matchup_score`
comparisons, and other estimate-based expressions — not on `resists`, `is_immune`, `knows`,
`has_hazard`, or field facts.
