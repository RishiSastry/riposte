# E022 — unknown predicate

**Cause:** You called a predicate that doesn't exist in Riposte. The language has a fixed
predicate library — you cannot define your own functions.

**Broken:** `mega_ko` is not a predicate:
```
when likely(mega_ko(my.active, opponent.active))
do use strongest_move against opponent.active
```

**Fixed:** use a real predicate (see topic `predicates` or `predicate_reference("<name>")`):
```
when likely(can_ko(my.active, opponent.active))
do use strongest_move against opponent.active
```

The full list is in the `predicates` topic. Common ones: `can_ko`, `guaranteed_ko`,
`outspeeds`, `resists`, `is_immune`, `effectiveness`, `matchup_score`, `knows`, `revealed`,
`has_hazard`.
