# E020 — unrevealed information

**Cause:** You tried to read information a legal player cannot see — most often
`opponent.active.moves`. The opponent's full move set is hidden; you only know what they have
**revealed** this battle.

**Broken:**
```
when opponent.active.moves
do switch_to best bench by matchup_score(it, opponent.active)
```

**Fixed:** ask only about revealed moves:
```
when revealed(opponent.active, "earthquake")
do switch_to best bench by matchup_score(it, opponent.active)
```

There is no syntax for peeking at hidden state — this is by design. Use `revealed(...)` for
opponent moves, and remember opponent `stats`/`ability`/`item` are **estimates**, not facts.
