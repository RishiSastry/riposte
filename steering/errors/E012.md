# E012 — syntax error

**Cause:** The parser expected a different token here — a missing `:`, `do`, `when`, `)`, or a
malformed expression/action. The message names what was expected.

**Fix:** compare against the shapes in `overview` (program/rule) and `actions`. The parser
recovers at the next `rule`/`otherwise`/`on`, so one run can report several syntax errors at
once — fix them top to bottom.
