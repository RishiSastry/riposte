# E030 — condition has type tribool; `when` requires bool

**Cause:** You used an estimate-based comparison (a `tribool`) directly where a `bool` is
required. Because opponent stats are estimates, predicates like `can_ko` and `outspeeds`
return `tribool` (yes / no / unknown), and you must resolve them.

**Broken:**
```
when can_ko(my.active, opponent.active)
do use strongest_move against opponent.active
```

**Fixed:** wrap it in exactly one resolver — `likely`, `worst_case`, or `best_case`:
```
when likely(can_ko(my.active, opponent.active))
do use strongest_move against opponent.active
```

`likely` = true at the median estimate (or across the whole range). `worst_case` assumes the
opponent's most favorable value; `best_case` assumes yours. See topic `types_and_estimates`.
