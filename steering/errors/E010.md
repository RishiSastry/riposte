# E010 — unrecognized token

**Cause:** The lexer hit a character that isn't part of Riposte (e.g. `@`, `%`, `$`). Riposte
uses only letters, digits, `_`, `.`, `,`, `:`, `(`, `)`, the comparison operators
(`= != < <= > >=`), string literals in double quotes, and `#` line comments.

**Fix:** remove the stray character. If you meant a string (a move id), quote it: `"uturn"`.
